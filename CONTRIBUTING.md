# Contributing to reBoard

Thank you for your interest in reBoard!

## Code contributions

reBoard **does not accept code contributions**. Pull requests will be closed
without review. This keeps the project's scope, direction and licensing
simple to manage.

## Issues are welcome

Bug reports and feature requests are appreciated. When filing an issue,
please include:

- Your device model (reMarkable 1, reMarkable 2, Paper Pro) and OS version.
- What you did, what you expected, and what actually happened.
- Relevant logs if you have them (`journalctl -u reboard` on the device).

## Security

If you believe you have found a security issue, please open an issue asking
for a private contact channel instead of posting the details publicly.
